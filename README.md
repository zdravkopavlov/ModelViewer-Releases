# ModelViewer Library

Official Windows installers and update metadata for ModelViewer Library.
This repository distributes the application; it does not contain its source code.

## Download

Get the Windows x64 installer from [Releases](https://github.com/zdravkopavlov/ModelViewer-Releases/releases).
The installer includes .NET and WebView2 for offline setup. macOS is planned, not yet available.

Browse public sample models or sign in to your assigned collections at
[ModelViewer Portal](https://portal.bunchofpixels.com/).

## Alpha testing

These alpha installers are unsigned. Windows may display an unknown-publisher warning.
Verify downloads against the SHA256SUMS.txt attached to each release.
Installation does not require an account. Access to private collections requires an authorized account.
Use Make available offline to retain models for disconnected viewing.

## Updates

`current_version.json` is the desktop update channel. Updates are downloaded and installed manually.
Release tags identify specific builds; published installer files are not silently replaced.
